# Static Assets

This directory serves as the centralized repository for static images, application icons, and documentation attachments.

---

## Directory Organization

```text
assets/
├── icons/          # Permanent app & container icons for homelab dashboards
├── avatars/        # Profile pictures and personal branding assets
└── docs/           # Documentation screenshots and Obsidian attachments
```

- **App Icons**: See [assets/icons/README.md](icons/README.md) for permanent URL endpoints (GitHub Raw & jsDelivr CDN).
- **Obsidian Attachments**: Configured in `.obsidian/app.json` so dragged/pasted images land automatically in `assets/docs/`.
